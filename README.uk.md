Легка локальна вебпанель для **OpenCode V2**, яка допомагає переглядати використання токенів, вартість моделей, роботу інструментів і контекст сеансів за запитами просто у браузері.

Виконайте **`/usage-dashboard`** в OpenCode Mini або повному TUI, щоб відкрити панель. Вона працює в процесі плагіна OpenCode і не потребує додаткової бази даних чи фонового демона.

## Що можна переглянути

- **Огляд (`/stats`):** загальна кількість токенів, зафіксована вартість у USD, сеанси, кроки моделей, денна активність, розподіл токенів і тенденції денного використання токенів на вимогу.
- **Моделі (`/models`):** графіки й таблиці токенів та вартості за постачальником, моделлю та варіантом — із сортуванням за токенами, вартістю, кроками або назвою моделі.
- **Інструменти (`/tools`):** кількість викликів, число успішних, невдалих і незавершених викликів, а також медіанний (`P50`) час виконання для кожного інструмента.
- **Сеанси й контекст запитів (`/sessions`):** пошук сеансів за назвою, перехід між батьківськими та дочірніми сеансами, перегляд часових шкал токенів і вартості за запитами та збереженої історії до будь-якого вибраного кроку.

## Швидкий початок

Додайте плагін до `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["github:createOne999/oud#release"]
}
```

Потім виконайте **`/usage-dashboard`** в OpenCode, щоб відкрити панель у браузері за замовчуванням, або перейдіть безпосередньо на <http://127.0.0.1:7331/stats> (також працюють `http://localhost:7331/stats` і `http://[::1]:7331/stats`).

### Налаштування порту

Порт за замовчуванням — `7331`. Якщо одночасно запущено кілька проєктів або потрібен інший порт, задайте `options.port` (використайте `0`, щоб автоматично вибрати будь-який вільний порт):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    { "package": "github:createOne999/oud#release", "options": { "port": 7332 } }
  ]
}
```

## Використання панелі

- **Фільтри дат і проєктів:** початково вибрано поточний місяць і поточний проєкт у часовому поясі браузера (кінцева дата включно). У будь-який момент можна вибрати **Усі проєкти** або окремий проєкт.
- **Багатомовний інтерфейс:** змінюйте мову у верхньому списку. Вибрана мова (`?lang=...`), діапазон дат, фільтр проєктів і посилання на активний запит зберігаються в URL, тож будь-яке подання можна легко додати в закладки або оновити.
- **Денний розподіл токенів:** на сторінці «Огляд» натисніть **Завантажити денні токени**, щоб переглянути графіки вхідних і вихідних токенів, міркувань і читання/запису кешу за днями для вибраного періоду.
- **Перегляд контексту запиту:**
  1. Відкрийте **Сеанси / запити** та виберіть сеанс (скористайтеся позначкою або розділом **Дочірні сеанси**, щоб перейти до пов'язаних сеансів субагентів).
  2. Натисніть точку на графіку запитів або часову позначку в таблиці запитів.
  3. Перегляньте **Збережену історію перед запитом** (зокрема запити користувача, попередні відповіді, виклики інструментів, навички та підсумки стискання) поруч із **Відповіддю на вибраний запит**.
  4. Натискайте **Завантажити ще 100 записів історії**, щоб переглянути попередні повідомлення довгого сеансу.

### Корисні примітки щодо показників

- **Кількість токенів:** відображається в компактних одиницях `K`, `M`, `B` і `T` (до двох знаків після коми), тоді як сортування й підсумки використовують точні числа. Загальна кількість токенів дорівнює `input + output + reasoning + cache.read + cache.write`.
- **Оцінка вартості:** вартість у USD обчислюється на основі даних про використання від постачальника та тарифів із каталогу моделей і надається для зручності.
- **Перегляд збереженого контексту:** інспектор запитів відновлює контекст зі збереженої історії сеансу та завершених меж стискання до вибраного кроку.

## Локальність і приватність за задумом

- **Лише loopback:** панель прив'язується виключно до локального loopback (`127.0.0.1` і `::1`) і перевіряє заголовки того самого джерела, тож дані використання доступні лише на вашому комп'ютері.
- **Без додаткового сховища й телеметрії:** дані на вимогу зчитуються із запущеної локальної спільної служби OpenCode V2. Усі ресурси інтерфейсу й переклади входять до локального пакета; зовнішні CDN, аналітика чи додаткові файли даних не використовуються. Щоб видалити плагін, просто вилучіть його запис із `opencode.json`.

## Запуск із вихідного коду

Зібрано для OpenCode **2.2.0** і Bun **1.4.2**. У корені репозиторію виконайте:

```powershell
bun run setup
opencode mini
# Inside OpenCode: /usage-dashboard
```

Якщо ви працюєте у віддаленому середовищі, WSL або без графічного інтерфейсу, де браузер не може відкритися автоматично, перевірте активну URL-адресу панелі та її готовність у терміналі:

```powershell
bun run status
```
