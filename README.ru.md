Лёгкая локальная веб-панель для **OpenCode V2**, которая позволяет прямо в браузере изучать использование токенов, стоимость моделей, производительность инструментов и контекст сессий для каждого запроса.

Чтобы открыть панель, выполните **`/usage-dashboard`** в OpenCode Mini или полной TUI. Она работает в процессе плагина OpenCode, без дополнительной базы данных или фоновой службы.

![OpenCode Usage Dashboard](screenshot.png)

## Что можно изучить

- **Обзор (`/stats`):** Общее число токенов, учтённая стоимость в USD, сессии, Steps моделей, активность по дням, состав токенов и динамика токенов по дням по запросу.
- **Модели (`/models`):** Графики и таблицы токенов и стоимости по провайдеру, модели и Variant — с сортировкой по числу токенов, стоимости, Steps или названию модели.
- **Инструменты (`/tools`):** Число вызовов, количество успешных, неудачных и незавершённых вызовов, а также медианное время выполнения (`P50`) для каждого инструмента.
- **Сессии и контекст запросов (`/sessions`):** Поиск сессий по названию, переход между родительскими и дочерними сессиями, просмотр хронологии токенов и стоимости по запросам и сохранённой истории до любого выбранного шага.

## Быстрый старт

Добавьте плагин в `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["github:createOne999/opencode-usage-webui#release"]
}
```

Затем выполните **`/usage-dashboard`** в OpenCode, чтобы открыть панель в браузере по умолчанию, или перейдите по адресу <http://127.0.0.1:7331/stats> напрямую (`http://localhost:7331/stats` и `http://[::1]:7331/stats` тоже работают).

### Настройка порта

Порт по умолчанию — `7331`. Если одновременно запущено несколько проектов или нужен другой порт, задайте `options.port` (укажите `0`, чтобы автоматически выбрать любой свободный порт):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    { "package": "github:createOne999/opencode-usage-webui#release", "options": { "port": 7332 } }
  ]
}
```

## Использование панели

- **Фильтры дат и проектов:** По умолчанию выбраны текущий месяц и текущий проект в часовом поясе браузера (дата окончания включена). В любой момент можно переключиться на **Все проекты** или выбрать отдельный проект.
- **Многоязычный интерфейс:** Переключайте язык с помощью селектора вверху. Выбранный язык (`?lang=...`), диапазон дат, фильтр проекта и ссылка на активный запрос сохраняются в URL — любой вид можно легко добавить в закладки или обновить.
- **Разбивка токенов по дням:** На странице «Обзор» нажмите **Загрузить дневные токены**, чтобы увидеть графики ввода, вывода, рассуждений и чтения/записи кэша по дням за выбранный период.
- **Просмотр контекста запроса:**
  1. Откройте **Сессии / запросы** и выберите сессию (используйте метку или раздел **Дочерние сессии**, чтобы перейти между связанными сессиями субагентов).
  2. Нажмите точку на графике запросов или отметку времени в таблице запросов.
  3. Просмотрите **Сохранённую историю до запроса** (включая запросы пользователя, предыдущие ответы, вызовы инструментов, навыки и сводки сжатия) рядом с **Ответом на выбранный запрос**.
  4. Нажимайте **Загрузить ещё 100 записей истории**, чтобы просматривать более ранние сообщения длинной сессии.

### Полезные примечания о метриках

- **Количество токенов:** Отображается в компактных единицах `K`, `M`, `B` и `T` (до двух знаков после запятой); сортировка и итоги используют точные числа. Общее число токенов равно `input + output + reasoning + cache.read + cache.write`.
- **Оценка стоимости:** Стоимость в USD рассчитывается по данным об использовании от провайдера и тарифам каталога моделей и предназначена для справки.
- **Просмотр сохранённого контекста:** Инспектор запросов восстанавливает контекст по сохранённой истории сессии и завершённым границам сжатия до выбранного шага.

## Локально и конфиденциально

- **Только локальный интерфейс:** Панель привязывается только к локальному интерфейсу (`127.0.0.1` и `::1`) и проверяет заголовки одного источника, поэтому данные использования доступны только на вашем компьютере.
- **Без дополнительного хранения и телеметрии:** По запросу читает данные работающей локальной общей службы OpenCode V2. Все ресурсы интерфейса и переводы включены локально; внешние CDN, аналитика и дополнительные файлы данных не используются. Чтобы удалить плагин, просто удалите его запись из `opencode.json`.

## Запуск из исходного кода

Требуются OpenCode **2.2.0** и Bun **1.4.2**. Выполните команды из корня репозитория:

```powershell
bun run setup
opencode mini
# Inside OpenCode: /usage-dashboard
```

Если вы работаете в удалённой среде, WSL или без графической оболочки, где браузер не может открыться автоматически, проверьте активный URL панели и её готовность в терминале:

```powershell
bun run status
```

bun run build
