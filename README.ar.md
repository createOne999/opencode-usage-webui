لوحة معلومات ويب محلية وخفيفة لـ **OpenCode V2** تساعدك على استكشاف استخدام الرموز وتكاليف النماذج وأداء الأدوات وسياق الجلسة لكل طلب، مباشرةً في متصفحك.

شغّل **`/usage-dashboard`** في OpenCode Mini أو واجهة TUI الكاملة لفتح لوحة المعلومات متى شئت. تعمل ضمن عملية إضافة OpenCode، ولا تحتاج إلى قاعدة بيانات إضافية أو خدمة خلفية.

## ما يمكنك استكشافه

- **نظرة عامة (`/stats`):** إجمالي الرموز والتكلفة المسجلة بـ USD والجلسات وخطوات النماذج والنشاط اليومي وتفصيل الرموز واتجاهات الرموز اليومية عند الطلب.
- **النماذج (`/models`):** مخططات وجداول الرموز والتكلفة حسب الموفر والنموذج والنسخة، مع إمكانية الترتيب حسب الرموز أو التكلفة أو الخطوات أو اسم النموذج.
- **الأدوات (`/tools`):** حجم الاستدعاءات وأعداد النجاح والفشل وعدم الاكتمال ومدة التنفيذ الوسيطة (`P50`) لكل أداة.
- **الجلسات وسياق الطلب (`/sessions`):** البحث عن الجلسات حسب العنوان، والتنقل بين الجلسات الأصل والفرعية، وفحص الجداول الزمنية للرموز والتكلفة لكل طلب، وعرض السجل المحفوظ الذي يسبق أي خطوة محددة.

## البدء السريع

أضف الإضافة إلى `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["github:createOne999/opencode-usage-webui#release"]
}
```

ثم شغّل **`/usage-dashboard`** داخل OpenCode لفتح لوحة المعلومات في متصفحك الافتراضي، أو انتقل مباشرةً إلى <http://127.0.0.1:7331/stats> (يعمل أيضًا كل من `http://localhost:7331/stats` و`http://[::1]:7331/stats`).

### تخصيص المنفذ

المنفذ الافتراضي هو `7331`. إذا شغّلت عدة مشاريع في الوقت نفسه أو أردت استخدام منفذ مختلف، فاضبط `options.port` (استخدم `0` لاختيار أي منفذ متاح تلقائيًا):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    { "package": "github:createOne999/opencode-usage-webui#release", "options": { "port": 7332 } }
  ]
}
```

## استخدام لوحة المعلومات

- **مرشحات التاريخ والمشروع:** تستخدم افتراضيًا الشهر الحالي والمشروع الحالي وفق المنطقة الزمنية لمتصفحك (مع تضمين تاريخ النهاية). يمكنك التبديل إلى **كل المشاريع** أو أي مشروع بعينه في أي وقت.
- **واجهة متعددة اللغات:** بدّل اللغة من المحدد العلوي. تُحفظ اللغة المحددة (`?lang=...`) ونطاق التاريخ ومرشح المشروع ورابط الطلب النشط في URL لتتمكن بسهولة من حفظ أي عرض في الإشارات المرجعية أو تحديثه.
- **تفصيل الرموز اليومية:** في صفحة النظرة العامة، انقر **تحميل الرموز اليومية** لعرض مخططات يومية لرموز الإدخال والإخراج والاستدلال وقراءة الذاكرة المؤقتة وكتابتها ضمن الفترة المحددة.
- **فحص سياق الطلب:**
  1. افتح **الجلسات / الطلبات** واختر جلسة (استخدم شارة **الجلسات الفرعية** أو قسمها للتنقل بين جلسات الوكلاء الفرعية المرتبطة).
  2. انقر نقطة في مخطط الطلبات أو طابعًا زمنيًا في جدول الطلبات.
  3. استعرض **السجل المحفوظ قبل الطلب** (بما يشمل مطالبات المستخدم والاستجابات السابقة واستدعاءات الأدوات والمهارات وملخصات الضغط) إلى جانب **استجابة الطلب المحدد**.
  4. استخدم **تحميل 100 إدخال إضافي من السجل** متى أردت فحص رسائل أقدم في جلسة طويلة.

### ملاحظات مفيدة حول المقاييس

- **أعداد الرموز:** تُعرض بوحدات مختصرة `K` و`M` و`B` و`T` (حتى منزلتين عشريتين)، بينما يعتمد الترتيب والإجماليات على الأعداد الدقيقة. يساوي إجمالي الرموز `input + output + reasoning + cache.read + cache.write`.
- **تقديرات التكلفة:** تُعرض التكاليف بـ USD استنادًا إلى الاستخدام الذي يبلّغ عنه الموفر وأسعار دليل النماذج، لتكون مرجعًا ملائمًا.
- **عرض السياق المحفوظ:** يعيد فاحص الطلب بناء السياق من سجل الجلسة المحفوظ وحدود الضغط المكتملة حتى الخطوة المحددة.

## محلي وخاص بطبيعته

- **اتصال محلي فقط:** يرتبط حصريًا بعنوان loopback المحلي (`127.0.0.1` و`::1`) ويتحقق من ترويسات المصدر نفسه، لتبقى بيانات الاستخدام متاحة على جهازك وحده.
- **دون تخزين إضافي أو قياس عن بُعد:** يقرأ عند الطلب من خدمة OpenCode V2 المحلية المشتركة قيد التشغيل. تُضمّن جميع أصول الواجهة والترجمات محليًا دون شبكات CDN خارجية أو تحليلات أو ملفات بيانات إضافية. لإلغاء التثبيت، ما عليك سوى إزالة إدخال الإضافة من `opencode.json`.

## التشغيل من المصدر

مبني لـ OpenCode **2.2.0** وBun **1.4.2**. من جذر المستودع:

```powershell
bun run setup
opencode mini
# Inside OpenCode: /usage-dashboard
```

إذا كنت تعمل في بيئة بعيدة أو WSL أو بلا واجهة، حيث لا يمكن فتح المتصفح تلقائيًا، فتحقق من عنوان لوحة المعلومات النشط وجاهزيتها من الطرفية:

```powershell
bun run status
```
