একটি হালকা ও স্থানীয় ওয়েব ড্যাশবোর্ড, যা **OpenCode V2**-এর টোকেন ব্যবহার, মডেল খরচ, টুলের কার্যকারিতা এবং প্রতিটি অনুরোধের সেশন প্রসঙ্গ ব্রাউজারেই খতিয়ে দেখতে সাহায্য করে।

ড্যাশবোর্ড খুলতে OpenCode Mini অথবা পূর্ণ TUI-তে **`/usage-dashboard`** চালান। এটি OpenCode প্লাগইন প্রক্রিয়ার মধ্যেই চলে; অতিরিক্ত ডেটাবেস বা ব্যাকগ্রাউন্ড ডেমন লাগে না।

![OpenCode Usage Dashboard](screenshot.png)

## যা যা দেখা যাবে

- **সারাংশ (`/stats`):** মোট টোকেন, নথিভুক্ত USD খরচ, সেশন, মডেল ধাপ, দৈনিক কার্যকলাপ, টোকেনের বিভাজন এবং চাহিদামতো দৈনিক টোকেনের প্রবণতা।
- **মডেল (`/models`):** সরবরাহকারী, মডেল ও ভ্যারিয়েন্ট অনুযায়ী টোকেন ও খরচের চার্ট এবং সারণি—টোকেন, খরচ, ধাপ বা মডেলের নাম অনুযায়ী সাজানো যায়।
- **টুল (`/tools`):** প্রতিটি টুলের কলের সংখ্যা, সফল/ব্যর্থ/অসম্পূর্ণ কলের হিসাব এবং মধ্যম (`P50`) চালানোর সময়।
- **সেশন ও অনুরোধের প্রসঙ্গ (`/sessions`):** শিরোনাম দিয়ে সেশন খুঁজুন, মূল ও শিশু সেশনের মধ্যে যান, প্রতিটি অনুরোধের টোকেন ও খরচের সময়রেখা দেখুন, এবং নির্বাচিত ধাপ পর্যন্ত সংরক্ষিত ইতিহাস পর্যালোচনা করুন।

## দ্রুত শুরু

আপনার `opencode.json`-এ প্লাগইনটি যোগ করুন:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["github:createOne999/opencode-usage-webui#release"]
}
```

এরপর ডিফল্ট ব্রাউজারে ড্যাশবোর্ড খুলতে OpenCode-এর ভেতরে **`/usage-dashboard`** চালান, অথবা সরাসরি <http://127.0.0.1:7331/stats> দেখুন (`http://localhost:7331/stats` এবং `http://[::1]:7331/stats`-ও কাজ করে)।

### পোর্ট পরিবর্তন

ডিফল্ট পোর্ট হলো `7331`। একাধিক প্রকল্প একসঙ্গে চালালে বা অন্য পোর্ট ব্যবহার করতে চাইলে `options.port` নির্ধারণ করুন (যেকোনো উপলভ্য পোর্ট স্বয়ংক্রিয়ভাবে বেছে নিতে `0` ব্যবহার করুন):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    { "package": "github:createOne999/opencode-usage-webui#release", "options": { "port": 7332 } }
  ]
}
```

## ড্যাশবোর্ড ব্যবহার

- **তারিখ ও প্রকল্পের ফিল্টার:** ব্রাউজারের সময় অঞ্চলে বর্তমান মাস এবং বর্তমান প্রকল্প দিয়ে শুরু হয় (শেষ তারিখও অন্তর্ভুক্ত)। যেকোনো সময় **সব প্রকল্প** বা নির্দিষ্ট প্রকল্প বেছে নিতে পারেন।
- **বহুভাষিক ইন্টারফেস:** উপরের নির্বাচক থেকে ভাষা বদলান। নির্বাচিত ভাষা (`?lang=...`), তারিখের পরিসর, প্রকল্পের ফিল্টার এবং সক্রিয় অনুরোধের লিংক URL-এ থাকে, তাই যেকোনো দৃশ্য সহজেই বুকমার্ক বা রিফ্রেশ করা যায়।
- **দৈনিক টোকেনের বিভাজন:** সারাংশ পাতায় **দৈনিক টোকেন লোড করুন**-এ ক্লিক করে নির্বাচিত সময়সীমার প্রতিদিনের ইনপুট, আউটপুট, যুক্তি এবং ক্যাশ পড়া/লেখার টোকেনের চার্ট দেখুন।
- **অনুরোধের প্রসঙ্গ খতিয়ে দেখা:**
  1. **সেশন / অনুরোধ** খুলে একটি সেশন নির্বাচন করুন (সম্পর্কিত সাবএজেন্ট সেশনে যেতে **শিশু সেশন** ব্যাজ বা বিভাগ ব্যবহার করুন)।
  2. অনুরোধের চার্টে একটি বিন্দুতে অথবা অনুরোধের সারণিতে কোনো সময়চিহ্নে ক্লিক করুন।
  3. নির্বাচিত অনুরোধের **উত্তর**-এর পাশাপাশি **অনুরোধের আগের সংরক্ষিত ইতিহাস** দেখুন (এতে ব্যবহারকারীর প্রম্পট, আগের উত্তর, টুল কল, দক্ষতা ও সংক্ষেপণের সারাংশ রয়েছে)।
  4. দীর্ঘ সেশনের আগের বার্তাগুলো দেখতে চাইলে **ইতিহাসের আরও 100টি এন্ট্রি লোড করুন** ব্যবহার করুন।

### পরিমাপ সম্পর্কে দরকারি তথ্য

- **টোকেনের হিসাব:** সংক্ষিপ্ত `K`, `M`, `B` এবং `T` এককে (সর্বোচ্চ দুই দশমিক ঘর পর্যন্ত) দেখানো হয়; তবে সাজানো ও মোট হিসাবের জন্য সঠিক সংখ্যা ব্যবহৃত হয়। মোট টোকেন = `input + output + reasoning + cache.read + cache.write`।
- **খরচের আনুমানিক হিসাব:** সহজে বোঝার জন্য সরবরাহকারীর জানানো ব্যবহার এবং মডেল ক্যাটালগের দর অনুযায়ী খরচ USD-তে দেখানো হয়।
- **সংরক্ষিত প্রসঙ্গের দৃশ্য:** অনুরোধ পরিদর্শক নির্বাচিত ধাপ পর্যন্ত সংরক্ষিত সেশন ইতিহাস এবং সম্পন্ন সংক্ষেপণ-সীমানা থেকে প্রসঙ্গ পুনর্গঠন করে।

## নকশাতেই স্থানীয় ও ব্যক্তিগত

- **শুধু লুপব্যাক:** কেবল স্থানীয় লুপব্যাক (`127.0.0.1` এবং `::1`)-এ সংযোগ স্থাপন করে এবং একই-উৎসের হেডার যাচাই করে, যাতে আপনার ব্যবহারের তথ্য শুধু আপনার যন্ত্রেই দেখা যায়।
- **অতিরিক্ত সংরক্ষণ বা টেলিমেট্রি নেই:** প্রয়োজনমতো চালু থাকা স্থানীয় OpenCode V2 শেয়ার্ড সার্ভিস থেকে তথ্য পড়ে। সব ইন্টারফেসের সম্পদ ও অনুবাদ স্থানীয়ভাবে অন্তর্ভুক্ত; কোনো বাহ্যিক CDN, বিশ্লেষণ ব্যবস্থা বা অতিরিক্ত তথ্য-ফাইল নেই। আনইনস্টল করতে `opencode.json` থেকে প্লাগইন এন্ট্রিটি সরিয়ে দিন।

## সোর্স থেকে চালান

OpenCode **2.2.0** এবং Bun **1.4.2**-এর জন্য তৈরি। রিপোজিটরির মূল ডিরেক্টরি থেকে:

```powershell
bun run setup
opencode mini
# Inside OpenCode: /usage-dashboard
```

দূরবর্তী, WSL বা হেডলেস পরিবেশে কাজ করলে—যেখানে ব্রাউজার স্বয়ংক্রিয়ভাবে খোলে না—টার্মিনাল থেকে সক্রিয় ড্যাশবোর্ড URL ও প্রস্তুতির অবস্থা দেখুন:

```powershell
bun run status
```

### ডেভেলপমেন্ট যাচাই

```powershell
bun run build
bun run typecheck
bun run test
```
