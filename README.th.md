เว็บแดชบอร์ดภายในเครื่องขนาดเล็กสำหรับ **OpenCode V2** ช่วยสำรวจการใช้โทเค็น ค่าใช้จ่ายโมเดล ประสิทธิภาพเครื่องมือ และบริบทเซสชันรายคำขอได้จากเบราว์เซอร์

เรียกใช้ **`/usage-dashboard`** ใน OpenCode Mini หรือ TUI ตัวเต็มได้ทุกเมื่อเพื่อเปิดแดชบอร์ด แดชบอร์ดทำงานภายในกระบวนการปลั๊กอิน OpenCode โดยไม่ต้องใช้ฐานข้อมูลหรือ daemon เบื้องหลังเพิ่มเติม

## สิ่งที่สำรวจได้

- **ภาพรวม (`/stats`):** โทเค็นทั้งหมด ค่าใช้จ่าย USD ที่บันทึกไว้ เซสชัน Steps ของโมเดล กิจกรรมรายวัน การแจกแจงโทเค็น และแนวโน้มโทเค็นรายวันที่เรียกดูได้ตามต้องการ
- **โมเดล (`/models`):** กราฟและตารางโทเค็นกับค่าใช้จ่ายแยกตามผู้ให้บริการ โมเดล และ variant—เรียงตามโทเค็น ค่าใช้จ่าย Steps หรือชื่อโมเดลได้
- **เครื่องมือ (`/tools`):** ปริมาณการเรียก จำนวนที่สำเร็จ/ล้มเหลว/ไม่สมบูรณ์ และเวลาทำงานมัธยฐาน (`P50`) ของแต่ละเครื่องมือ
- **เซสชันและบริบทคำขอ (`/sessions`):** ค้นหาเซสชันตามชื่อ สลับดูเซสชันแม่และเซสชันย่อย ตรวจสอบไทม์ไลน์โทเค็นและค่าใช้จ่ายรายคำขอ และดูประวัติที่บันทึกไว้ก่อน Step ที่เลือก

## เริ่มต้นอย่างรวดเร็ว

เพิ่มปลั๊กอินลงใน `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["github:createOne999/opencode-usage-webui#release"]
}
```

จากนั้นเรียกใช้ **`/usage-dashboard`** ภายใน OpenCode เพื่อเปิดแดชบอร์ดในเบราว์เซอร์เริ่มต้น หรือไปที่ <http://127.0.0.1:7331/stats> โดยตรง (`http://localhost:7331/stats` และ `http://[::1]:7331/stats` ก็ใช้ได้เช่นกัน)

### ปรับแต่งพอร์ต

พอร์ตเริ่มต้นคือ `7331` หากเรียกใช้หลายโปรเจกต์พร้อมกันหรือต้องการพอร์ตอื่น ให้กำหนด `options.port` (ใช้ `0` เพื่อเลือกพอร์ตว่างโดยอัตโนมัติ):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    { "package": "github:createOne999/opencode-usage-webui#release", "options": { "port": 7332 } }
  ]
}
```

## การใช้แดชบอร์ด

- **ตัวกรองวันที่และโปรเจกต์:** ค่าเริ่มต้นคือเดือนปัจจุบันและโปรเจกต์ปัจจุบันในเขตเวลาของเบราว์เซอร์ (รวมวันที่สิ้นสุด) คุณสามารถเปลี่ยนเป็น **ทุกโปรเจกต์** หรือโปรเจกต์ใดก็ได้
- **ส่วนติดต่อหลายภาษา:** เปลี่ยนภาษาจากตัวเลือกด้านบน ภาษาที่เลือก (`?lang=...`) ช่วงวันที่ ตัวกรองโปรเจกต์ และลิงก์คำขอที่ใช้งานอยู่จะอยู่ใน URL เพื่อให้บันทึกหน้าหรือรีเฟรชได้สะดวก
- **แจกแจงโทเค็นรายวัน:** ในหน้าภาพรวม คลิก **โหลดโทเค็นรายวัน** เพื่อดูกราฟโทเค็นอินพุต เอาต์พุต การให้เหตุผล และการอ่าน/เขียนแคชแยกตามวันในช่วงที่เลือก
- **ตรวจสอบบริบทคำขอ:**
  1. เปิด **เซสชัน / คำขอ** แล้วเลือกเซสชัน (ใช้ป้ายหรือส่วน **เซสชันย่อย** เพื่อสลับไปมาระหว่างเซสชันของเอเจนต์ย่อยที่เกี่ยวข้อง)
  2. คลิกจุดบนกราฟคำขอหรือเวลาประทับในตารางคำขอ
  3. เรียกดู **ประวัติที่บันทึกไว้ก่อนคำขอ** (รวมพรอมป์ต์ผู้ใช้ คำตอบก่อนหน้า การเรียกเครื่องมือ สกิล และสรุปการบีบอัด) ควบคู่กับ **การตอบกลับของคำขอที่เลือก**
  4. ใช้ **โหลดประวัติเพิ่มอีก 100 รายการ** เมื่อต้องการตรวจสอบข้อความก่อนหน้าในเซสชันยาว

### หมายเหตุที่เป็นประโยชน์เกี่ยวกับตัวชี้วัด

- **จำนวนโทเค็น:** แสดงด้วยหน่วยย่อ `K`, `M`, `B` และ `T` (สูงสุดสองตำแหน่งทศนิยม) ส่วนการเรียงลำดับและยอดรวมใช้ตัวเลขที่แม่นยำ ยอดโทเค็นทั้งหมดเท่ากับ `input + output + reasoning + cache.read + cache.write`
- **ประมาณการค่าใช้จ่าย:** ค่าใช้จ่ายแสดงเป็น USD โดยอ้างอิงการใช้งานที่ผู้ให้บริการรายงานและอัตราจากแคตตาล็อกโมเดล เพื่อใช้อ้างอิงได้สะดวก
- **มุมมองบริบทที่บันทึกไว้:** ตัวตรวจสอบคำขอสร้างบริบทขึ้นใหม่จากประวัติเซสชันที่บันทึกไว้และขอบเขตการบีบอัดที่เสร็จสมบูรณ์จนถึง Step ที่เลือก

## ออกแบบมาให้ทำงานในเครื่องและเป็นส่วนตัว

- **เฉพาะ loopback:** ผูกการเชื่อมต่อกับ loopback ในเครื่องเท่านั้น (`127.0.0.1` และ `::1`) และตรวจสอบส่วนหัว same-origin เพื่อให้ข้อมูลการใช้งานเข้าถึงได้เฉพาะบนเครื่องของคุณ
- **ไม่มีพื้นที่จัดเก็บหรือ telemetry เพิ่มเติม:** อ่านข้อมูลตามต้องการจาก shared service ของ OpenCode V2 ในเครื่องที่กำลังทำงานอยู่ ไฟล์ UI และคำแปลทั้งหมดรวมไว้ในเครื่อง ไม่มี CDN ภายนอก analytics หรือไฟล์ข้อมูลเพิ่มเติม หากต้องการถอนการติดตั้ง เพียงลบรายการปลั๊กอินออกจาก `opencode.json`

## เรียกใช้จากซอร์ส

สร้างมาสำหรับ OpenCode **2.2.0** และ Bun **1.4.2** เรียกใช้จากรูทของ repository:

```powershell
bun run setup
opencode mini
# Inside OpenCode: /usage-dashboard
```

หากทำงานในสภาพแวดล้อม remote, WSL หรือ headless ที่ไม่สามารถเปิดเบราว์เซอร์โดยอัตโนมัติ ให้ตรวจสอบ URL แดชบอร์ดที่ใช้งานอยู่และสถานะพร้อมใช้งานจากเทอร์มินัล:

```powershell
bun run status
```
