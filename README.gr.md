Ένας ελαφρύς τοπικός πίνακας ελέγχου ιστού για το **OpenCode V2**, που σας βοηθά να εξερευνήσετε τη χρήση διακριτικών, το κόστος μοντέλων, την απόδοση εργαλείων και το περιεχόμενο συνεδριών ανά αίτημα απευθείας στο πρόγραμμα περιήγησής σας.

Εκτελέστε το **`/usage-dashboard`** στο OpenCode Mini ή στο πλήρες TUI όποτε θέλετε να ανοίξετε τον πίνακα ελέγχου. Λειτουργεί μέσα στη διεργασία του πρόσθετου OpenCode, χωρίς να απαιτείται πρόσθετη βάση δεδομένων ή υπηρεσία παρασκηνίου.

![OpenCode Usage Dashboard](screenshot.png)

## Τι μπορείτε να εξερευνήσετε

- **Επισκόπηση (`/stats`):** Σύνολο διακριτικών, καταγεγραμμένο κόστος σε USD, συνεδρίες, Steps μοντέλων, ημερήσια δραστηριότητα, ανάλυση διακριτικών και τάσεις ημερήσιων διακριτικών κατ' απαίτηση.
- **Μοντέλα (`/models`):** Γραφήματα και πίνακες διακριτικών και κόστους ανά πάροχο, μοντέλο και variant—με ταξινόμηση κατά διακριτικά, κόστος, Steps ή όνομα μοντέλου.
- **Εργαλεία (`/tools`):** Όγκος κλήσεων, πλήθος επιτυχιών/αποτυχιών/ημιτελών και διάμεσος χρόνος εκτέλεσης (`P50`) ανά εργαλείο.
- **Συνεδρίες και περιεχόμενο αιτημάτων (`/sessions`):** Αναζήτηση συνεδριών βάσει τίτλου, πλοήγηση μεταξύ γονικών και θυγατρικών συνεδριών, εξέταση χρονολογίων διακριτικών και κόστους ανά αίτημα και προβολή του αποθηκευμένου ιστορικού πριν από οποιοδήποτε επιλεγμένο βήμα.

## Γρήγορη εκκίνηση

Προσθέστε το πρόσθετο στο `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["github:createOne999/opencode-usage-webui#release"]
}
```

Στη συνέχεια, εκτελέστε το **`/usage-dashboard`** μέσα στο OpenCode για να ανοίξετε τον πίνακα ελέγχου στο προεπιλεγμένο πρόγραμμα περιήγησής σας ή επισκεφθείτε απευθείας το <http://127.0.0.1:7331/stats> (λειτουργούν επίσης τα `http://localhost:7331/stats` και `http://[::1]:7331/stats`).

### Προσαρμογή θύρας

Η προεπιλεγμένη θύρα είναι η `7331`. Αν εκτελείτε ταυτόχρονα πολλά έργα ή θέλετε διαφορετική θύρα, ορίστε το `options.port` (χρησιμοποιήστε `0` για αυτόματη επιλογή οποιασδήποτε διαθέσιμης θύρας):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    { "package": "github:createOne999/opencode-usage-webui#release", "options": { "port": 7332 } }
  ]
}
```

## Χρήση του πίνακα ελέγχου

- **Φίλτρα ημερομηνίας και έργου:** Ως προεπιλογή χρησιμοποιούνται ο τρέχων μήνας και το τρέχον έργο στη ζώνη ώρας του προγράμματος περιήγησής σας (συμπεριλαμβάνεται η ημερομηνία λήξης). Μπορείτε ανά πάσα στιγμή να επιλέξετε **Όλα τα έργα** ή ένα συγκεκριμένο έργο.
- **Πολύγλωσσο περιβάλλον:** Αλλάξτε γλώσσα από τον επάνω επιλογέα. Η επιλεγμένη γλώσσα (`?lang=...`), το εύρος ημερομηνιών, το φίλτρο έργου και ο σύνδεσμος ενεργού αιτήματος παραμένουν στη διεύθυνση URL, ώστε να αποθηκεύετε εύκολα στους σελιδοδείκτες ή να ανανεώνετε οποιαδήποτε προβολή.
- **Ημερήσια ανάλυση διακριτικών:** Στη σελίδα Επισκόπηση, πατήστε **Φόρτωση ημερήσιων διακριτικών** για να δείτε γραφήματα εισόδου, εξόδου, συλλογισμού και ανάγνωσης/εγγραφής προσωρινής μνήμης ανά ημέρα για το επιλεγμένο διάστημα.
- **Εξέταση περιεχομένου αιτήματος:**
  1. Ανοίξτε τις **Συνεδρίες / αιτήματα** και επιλέξτε μια συνεδρία (χρησιμοποιήστε την ένδειξη ή την ενότητα **Θυγατρικές συνεδρίες** για μετάβαση μεταξύ σχετικών συνεδριών υπο-agent).
  2. Κάντε κλικ σε ένα σημείο του γραφήματος αιτημάτων ή σε χρονική σήμανση στον πίνακα αιτημάτων.
  3. Περιηγηθείτε στο **Αποθηκευμένο ιστορικό πριν από το αίτημα** (συμπεριλαμβανομένων προτροπών χρήστη, προηγούμενων απαντήσεων, κλήσεων εργαλείων, δεξιοτήτων και συνόψεων συμπύκνωσης) μαζί με την **Απάντηση στο επιλεγμένο αίτημα**.
  4. Επιλέξτε **Φόρτωση 100 ακόμη καταχωρίσεων ιστορικού** όποτε θέλετε να εξετάσετε παλαιότερα μηνύματα μιας μεγάλης συνεδρίας.

### Χρήσιμες σημειώσεις για τις μετρικές

- **Πλήθος διακριτικών:** Εμφανίζεται σε συμπτυγμένες μονάδες `K`, `M`, `B` και `T` (έως δύο δεκαδικά ψηφία), ενώ η ταξινόμηση και τα σύνολα χρησιμοποιούν ακριβείς αριθμούς. Τα συνολικά διακριτικά ισούνται με `input + output + reasoning + cache.read + cache.write`.
- **Εκτιμήσεις κόστους:** Το κόστος εμφανίζεται σε USD βάσει της χρήσης που αναφέρουν οι πάροχοι και των τιμών του καταλόγου μοντέλων, για εύκολη αναφορά.
- **Προβολή αποθηκευμένου περιεχομένου:** Ο επιθεωρητής αιτημάτων ανακατασκευάζει το περιεχόμενο από το αποθηκευμένο ιστορικό της συνεδρίας και τα ολοκληρωμένα όρια συμπύκνωσης έως το επιλεγμένο βήμα.

## Τοπικό και ιδιωτικό από σχεδιασμό

- **Μόνο τοπική σύνδεση:** Συνδέεται αποκλειστικά στην τοπική loopback (`127.0.0.1` και `::1`) και επικυρώνει τις κεφαλίδες ίδιας προέλευσης, ώστε τα δεδομένα χρήσης να είναι προσβάσιμα μόνο από τον υπολογιστή σας.
- **Χωρίς πρόσθετη αποθήκευση ή τηλεμετρία:** Διαβάζει κατ' απαίτηση από την ενεργή τοπική κοινόχρηστη υπηρεσία OpenCode V2. Όλα τα στοιχεία διεπαφής και οι μεταφράσεις είναι ενσωματωμένα τοπικά, χωρίς εξωτερικά CDN, αναλυτικά στοιχεία ή πρόσθετα αρχεία δεδομένων. Για απεγκατάσταση, απλώς αφαιρέστε την καταχώριση του πρόσθετου από το `opencode.json`.

## Εκτέλεση από τον πηγαίο κώδικα

Έχει δημιουργηθεί για OpenCode **2.2.0** και Bun **1.4.2**. Από τη ρίζα του αποθετηρίου:

```powershell
bun run setup
opencode mini
# Inside OpenCode: /usage-dashboard
```

Αν εργάζεστε σε απομακρυσμένο περιβάλλον, WSL ή περιβάλλον χωρίς γραφικό περιβάλλον όπου το πρόγραμμα περιήγησης δεν ανοίγει αυτόματα, ελέγξτε την ενεργή διεύθυνση URL του πίνακα ελέγχου και την ετοιμότητά του από το τερματικό:

```powershell
bun run status
```
